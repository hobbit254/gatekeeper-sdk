# gatekeeper_sdk

Gatekeeper for Dart and Flutter apps: PKCE sign-in, single-flight refresh, step-up and DPoP. For Flutter, [gatekeeper_flutter](https://pub.dev/packages/gatekeeper_flutter) adds secure storage and system-browser sign-in on top.

```sh
dart pub add gatekeeper_sdk
```

Guide: [integrating with Gatekeeper](https://github.com/hobbit254/gatekeeper-sdk/tree/main/docs). Source and examples: [hobbit254/gatekeeper-sdk](https://github.com/hobbit254/gatekeeper-sdk). Licence: Apache-2.0.
