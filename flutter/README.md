# gatekeeper_flutter

Flutter companion to [gatekeeper_sdk](https://pub.dev/packages/gatekeeper_sdk): tokens in the Keychain and Android Keystore, sign-in, step-up and sign-out through the system browser, and auth state for widgets.

```sh
flutter pub add gatekeeper_flutter
```

Register your app's custom-scheme redirect on its Gatekeeper client. Guide: [integrating with Gatekeeper](https://github.com/hobbit254/gatekeeper-sdk/tree/main/docs). Source: [hobbit254/gatekeeper-sdk](https://github.com/hobbit254/gatekeeper-sdk). Licence: Apache-2.0.
